# ADR-003 빈자리 정의: 충전중 → 충전대기

- 상태: 승인

## 맥락

처음에는 "사용할 수 없던 충전기가 충전대기가 된 순간"을 빈자리로 봤다. 사용할 수 없던 상태에는 충전중, 점검중, 운영중지가 들어간다. 서울 실데이터 약 1시간 분량(이벤트 857건)을 분석한 결과는 다음과 같다.

| 직전 상태 | 건수 | 패턴 |
|---|---|---|
| 충전중 | 544건 (540대) | 여러 운영사에 고르게 분포, 충전기당 최대 2건 |
| 운영중지 | 300건 (153대) | 전부 한 운영사. 충전소 3곳에서 같은 초에 최대 32대씩 일괄 전환 |
| 점검중 | 13건 | 정각에 한 운영사 충전기가 몰려서 전환 |

운영중지·점검중 해제는 운영사의 일괄 작업이다. 누군가 충전을 마치고 떠나 자리가 난 것이 아니다. 이를 빈자리로 보면 알림의 약 37%(313/857건)가 잡음이 된다.

## 결정

- 빈자리는 **충전중 → 충전대기**만으로 정의한다.
- 운영중지·점검중·통신이상·상태미확인에서 충전대기로 바뀐 것은 이벤트를 만들지 않는다. **상태 자체는 그대로 반영**한다.
- 직전 상태를 모르는 충전기(처음 본 충전기)는 기준 상태로만 기록한다.

## 결과

- 얻은 것: 사용자가 기대하는 "자리가 났다"에 맞는 이벤트만 발행한다.
- 감수한 것: 점검이 끝나 새로 사용 가능해진 충전기는 알림 대상이 아니다. 검색 결과의 사용 가능 대수에는 반영된다.
- 공공데이터로는 충전대기 상태의 충전 구역에 일반 차량이 주차해 있는지 알 수 없다. 그래서 이벤트 의미는 "충전기가 사용 가능 상태가 됨"이다.
